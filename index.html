Features

🔍 Multi-Agent Pipeline

4 specialized agents (Planner, Searcher, Analyst, Synthesizer) work together in an iterative loop — searching, analyzing gaps, and repeating until comprehensive.

📚 Source-Cited Reports

Every finding links to its origin URL. Reports include executive summary, structured sections, data tables, key takeaways, and areas of uncertainty.

🧠 2nd Brain Integration

Save research to your Obsidian vault as interlinked wiki notes with YAML frontmatter and [[wikilinks]] — fully searchable by other LLMs.

🆓 Free Web Search

Uses DuckDuckGo — no API key needed for web search. Only the LLM calls need an API key (any OpenAI-compatible provider works).

🔌 MCP Server

Works as a native MCP tool inside Claude Desktop, ChatGPT, Cursor, and any MCP-compatible client. Research from your chat, not a separate app.

🎨 Dark-Themed UI

Clean web interface with live progress streaming (SSE), agent status cards, and interactive report viewer. Host anywhere or use the MCP mode.

📦 Install in 3 Minutes

Option 1: Use in Claude Desktop (MCP)

Clone & install:
git clone https://github.com/mrdchiang/deepresearch.git
cd deepresearch
pip install -r requirements.txt
Set your API key (any OpenAI-compatible provider: OpenAI, DeepSeek, Groq, etc.)
# .env or shell
export OPENAI_API_KEY=***
export OPENAI_BASE_URL=https://api.deepseek.com/v1 # optional
export DEEPRESEARCH_MODEL=deepseek-chat # optional
Add to Claude Desktop config (macOS: ~/Library/Application Support/Claude/claude_desktop_config.json)
{
  "mcpServers": {
    "deepresearch": {
      "command": "python",
      "args": ["/path/to/deepresearch/mcp_server.py"],
      "env": {
        "OPENAI_API_KEY": "***"
      }
    }
  }
}
Restart Claude Desktop. Now type "Use deepresearch to investigate..." and Claude will call the multi-agent pipeline. You'll get a full cited report in your chat.

Option 2: Use as a Web App

python server.py
# Open http://localhost:5000

Clean web UI with live progress streaming. Host the index.html on GitHub Pages and run server.py on your machine.

Option 3: Use in ChatGPT (Custom GPT)

Run the server: python server.py (or deploy to a VPS)
Create a Custom GPT at chat.openai.com/gpts/editor
Add an Action with this OpenAPI schema pointing to your server:
{
  "openapi": "3.0.0",
  "info": { "title": "DeepResearch" },
  "servers": [{ "url": "http://your-server:5000" }],
  "paths": {
    "/api/research": {
      "post": { /* standard POST with question + depth */ }
    }
  }
}
